## 二、核心技术原理

### 2.1 Stable Diffusion LCM（潜在一致性模型）

本项目使用 **Stable Diffusion 1.5 LCM**（Latent Consistency Model）进行风格迁移。

#### 传统 Stable Diffusion

```
文本提示 → 迭代去噪（20-30步）→ 生成图像
```

- 需要多次迭代（20-30 步）
- 每步都要运行完整的 UNet 网络
- 速度慢，不适合实时应用

#### LCM 优化

```
文本提示 → 少量去噪（1-4步）→ 生成图像
```

- 通过知识蒸馏训练，减少迭代次数
- 只需 1-4 步即可生成高质量图像
- 适合实时视频处理

### 2.2 Img2Img（图像到图像）模式

本项目使用 **Img2Img** 模式，不是 Txt2Img：

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│   输入图像    │ ───► │   VAE 编码    │ ───► │   潜在空间    │
│  (摄像头帧)   │      │  压缩图像     │      │   (512x512)  │
└──────────────┘      └──────────────┘      └──────────────┘
                                                    │
                                                    ▼
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│   输出图像    │ ◄─── │   VAE 解码    │ ◄─── │   UNet 去噪   │
│  (风格化)     │      │  还原图像     │      │  (1-4步)     │
└──────────────┘      └──────────────┘      └──────────────┘
```

#### 关键参数：Strength（风格化强度）

| Strength | 效果 | 适用场景 |
|----------|------|----------|
| 0.3 | 几乎不变 | 轻微风格化 |
| **0.45** | **保留结构，改变外观** | **本项目默认** ✅ |
| 0.75 | 大幅改变 | 强风格化 |
| 1.0 | 完全重绘 | txt2img 效果 |

### 2.3 Prompt（提示词）控制风格

通过文本描述目标风格，模型会将输入图像向该风格方向转换：

```
输入：真实照片
Prompt: "anime style of"（动漫风格）
输出：动漫画风的照片
```

### 3.2 帧处理流程（每帧）

```
┌─────────────────────────────────────────────────────────────┐
│                    单帧处理流程                              │
└─────────────────────────────────────────────────────────────┘

Step 1: 读取摄像头帧
┌──────────────┐
│  1280×720    │  ← 摄像头原始分辨率
│  BGR 格式    │
└──────┬───────┘
       │
       ▼
Step 2: 预处理
┌──────────────┐
│  BGR → RGB   │  ← OpenCV 转换颜色空间
│  resize      │  ← 缩放到 512×512
│  归一化 [0,1]│  ← 像素值除以 255
│  HWC → NCHW  │  ← 转换维度顺序
└──────┬───────┘
       │
       ▼
Step 3: 推理（核心）
┌──────────────┐
│   VAE 编码    │  ← 512×512 → 64×64×4 潜在表示
│      ↓       │
│   UNet 去噪  │  ← 根据 prompt 进行 1-4 步去噪
│   (1-4步)    │
│      ↓       │
│   VAE 解码    │  ← 64×64×4 → 512×512×3 图像
└──────┬───────┘
       │
       ▼
Step 4: 后处理
┌──────────────┐
│  [0,1] → [0,255] │  ← 反归一化
│  NCHW → HWC      │  ← 转换维度顺序
│  RGB → BGR       │  ← 转换颜色空间
│  resize          │  ← 放大回 1280×720
└──────┬───────────┘
       │
       ▼
Step 5: 显示
┌──────────────────────────────────┐
│  ┌────────────┬────────────┐     │
│  │  原始画面   │  风格化画面 │     │  ← 并排对比
│  │  640×720   │  640×720   │     │
│  └────────────┴────────────┘     │
│  FPS: 15.2 | tensorrt | Style: 1│  ← 状态信息
└──────────────────────────────────┘
```

## 四、模型转换流程

### 4.1 转换概述

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│  PyTorch 模型 │ ───► │  ONNX 模型    │ ───► │ TensorRT 引擎│
│  (HuggingFace)│      │  (通用格式)   │      │  (优化格式)  │
│  ~4GB         │      │  ~4GB         │      │  ~100MB      │
└──────────────┘      └──────────────┘      └──────────────┘

转换命令:
python scripts/convert_tensorrt.py --all --models models
```

### 4.2 详细转换步骤

```
Step 1: 下载 PyTorch 模型
┌─────────────────────────────────────────────────────────────┐
│  从 HuggingFace 下载 LCM_Dreamshaper_v7                    │
│  - UNet (U-Net 去噪网络)                                   │
│  - VAE (变分自编码器)                                       │
│  - Tokenizer (文本编码器)                                   │
│  保存到: models/sd-v1-5/                                   │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
Step 2: 导出 ONNX
┌─────────────────────────────────────────────────────────────┐
│  使用 torch.onnx.export() 导出                             │
│  - UNet: latent + timestep + prompt → output               │
│  - VAE Encoder: image → latent                             │
│  保存到: models/onnx/style_1/unet.onnx                     │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
Step 3: 转换 TensorRT
┌─────────────────────────────────────────────────────────────┐
│  使用 TensorRT Parser 解析 ONNX                            │
│  - FP16 量化 (half precision)                              │
│  - 内存优化                                                 │
│  - 内核自动调优                                             │
│  保存到: models/trt/style_1.engine                          │
└─────────────────────────────────────────────────────────────┘
```

## 六、关键算法

### 6.1 Diffusion 去噪过程

```
原始图像 → 加噪 → 去噪（条件：prompt）→ 风格化图像

数学表达:
x₀ (原图) → xₜ (加噪) → xₜ₋₁ → ... → x₁ → x₀' (风格化)

LCM 简化:
xₜ → x₀' (一步完成)
```

### 6.2 VAE 编解码

```
编码器 (Encoder):
  输入: 512×512×3 (RGB图像)
  输出: 64×64×4 (潜在表示)
  压缩比: 8x

解码器 (Decoder):
  输入: 64×64×4 (潜在表示)
  输出: 512×512×3 (RGB图像)
```

### 6.3 UNet 去噪网络

```
UNet 结构:
┌─────────────────────────────────────────┐
│  输入: latent (64×64×4)                 │
│  条件: timestep + prompt embedding      │
│                                         │
│  ┌─────────┐                            │
│  │ Encoder │ ──► skip connections       │
│  │ (下采样)│     │                      │
│  └────┬────┘     │                      │
│       │          │                      │
│  ┌────▼────┐     │                      │
│  │ Bottleneck│◄──┘                      │
│  └────┬────┘                            │
│       │                                 │
│  ┌────▼────┐                            │
│  │ Decoder │ ◄── skip connections       │
│  │ (上采样)│                            │
│  └─────────┘                            │
│                                         │
│  输出: denoised latent (64×64×4)        │
└─────────────────────────────────────────┘
```

## 七、性能优化策略

### 7.1 模型优化

| 策略 | 方法 | 效果 |
|------|------|------|
| 量化 | FP16 半精度 | 显存减半，速度提升 |
| 裁剪 | 移除安全检查器 | 减少计算量 |
| 缓存 | 启用注意力切片 | 节省显存 |

### 7.2 推理优化

| 策略 | 方法 | 效果 |
|------|------|------|
| TensorRT | 图优化 + 内核调优 | 速度提升 3-5 倍 |
| 批处理 | batch=1（实时） | 最低延迟 |
| 异步 | CUDA Stream | 流水线并行 |

### 7.3 系统优化

```bash
# Jetson 性能模式
sudo nvpmodel -m 0      # MaxN 模式
sudo jetson_clocks       # 锁定最高频率

# 散热优化
echo 200 | sudo tee /sys/devices/pwm-fan/target_duty_cycle
```
